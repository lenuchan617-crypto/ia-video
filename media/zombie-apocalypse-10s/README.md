# ЗОМБИ-АПОКАЛИПСИС — 10-секундный ролик

Короткий кинематографичный ролик (10.0 с, 1920×1080, 24 fps, стерео AAC), собранный
**полностью процедурно**: ни одного внешнего ассета — ни видео, ни фото, ни сэмплов.
Всё, что видно и слышно, сгенерировано кодом в этом каталоге.

## Готовый файл

| файл | что это |
|---|---|
| `final/zombie_apocalypse_10s.mp4` | сам ролик, 10.0 с, H.264 High + AAC 192 kbps, `+faststart` |
| `final/poster.png` | постер-кадр 1920×1080 |

## Раскадровка

| время | сцена | содержание |
|---|---|---|
| 0.0 – 2.6 | **ДЕНЬ 47** | мёртвый город на рассвете, туман, мокрый асфальт, руины с окнами, одинокие силуэты зомби на дороге |
| 2.6 – 5.0 | **ОРДА** | толпа зомби выходит из светящейся стены тумана, объёмные лучи, глубина и расфокус ближнего плана |
| 5.0 – 7.6 | **КОРИДОР** | камера в тёмном коридоре, яркий проём в конце, силуэты поднимаются из света и идут на камеру |
| 7.6 – 8.6 | **ВЫЖИВШИЙ** | герой спиной к камере с битой на фоне орды |
| 8.6 – 10.0 | **ТИТР** | «ЗОМБИ-АПОКАЛИПСИС / НЕ ОСТАНАВЛИВАЙСЯ», красная дымка, искры |

Соотношение сторон кадра — 2.39:1 с чёрными полосами внутри 1080p (как в кино).

## Звук

Синтезирован в `audio.py` (NumPy → WAV): низкий гул-подушка, ветер, рычание орды
(аддитивный синтез с формантами), тяжёлые шаги, подъёмы напряжения, сердцебиение,
финальный «брэм» и удар. Удары привязаны к монтажным склейкам (2.6 / 5.0 / 8.6 с).

## Как пересобрать

Нужны Python 3.11, NumPy, Pillow и любой ffmpeg с libx264.

```bash
python3 -m venv .venv && .venv/bin/pip install numpy pillow imageio-ffmpeg
cd media/zombie-apocalypse-10s

# весь ролик (≈5 минут на 2 ядрах, 240 кадров)
../.venv/bin/python build.py

# постер
../.venv/bin/python build.py poster

# отдельные кадры для проверки
../.venv/bin/python build.py still 1.2 3.8 6.6 9.3

# только звук
../.venv/bin/python build.py audio
```

ffmpeg берётся из `imageio-ffmpeg`, системного PATH или переменной `FFMPEG`.

## Устройство

- `engine.py` — мини-движок: камера (наезд/панорама через `Image.AFFINE`), вертикальные
  градиенты, бесшовный периодический fBm для тумана и дыма, объёмные лучи, силуэты людей
  на SDF-полях, постобработка (тонмаппинг, сплит-тонирование, bloom, виньетка,
  хроматическая аберрация, зерно, мерцание, лоттербокс 2.39:1).
- `build.py` — пять сцен, раскадровка, сборка через pipe в ffmpeg.
- `audio.py` — синтез звуковой дорожки (свой мини-DSP: фильтры, огибающие, реверб).

## Ограничения

Графика стилизованная, силуэтно-графическая (не фотореализм): генератор изображений
был недоступен, поэтому лица и фактуры прорисованы процедурно. Для фотореалистичной
версии нужны кадры из генератора изображений / стоковые кадры — тогда `build.py`
подставляет их вместо процедурных слоёв.

# ТЕНЕВОЙ РАБ — Эпизод 1 «Лишённый Света»

Экранизация глав 1–5 веб-романа «Теневой раб» (Shadow Slave) в формате
**кинематографического аниматика** — 13:00, 24 fps, 1280×720.

| Файл | Что это |
|---|---|
| `Shadow_Slave_E01_Cherished_Light.mp4` | **Готовый эпизод, 13:00** (видео + звук + субтитры) |
| `scenario.md` | Производственная библия и покадровый сценарий: стиль, палитра, персонажи, 7 сцен |
| `storyboard.md` | Раскадровка: 80 шотов с таймкодами, движением камеры и репликами (генерируется автоматически) |
| `images/` | 37 ки-арт-плейтов 1672×941 |
| `audio/vo/` | 19 реплик, 4 голоса |
| `src/` | Воспроизводимый пайплайн (Python + ffmpeg) |

## Технические параметры

- Длительность **ровно 780.000 с** (контроль — `src/shots.py`, assert)
- 7 сцен / 80 шотов / средняя длина плана 9.75 с
- Виртуальная камера: наезды, отъезды, панорамы, тилты, дрейф (zoompan на плейте 3840×2160)
- Грейд: `eq` + `colorbalance` + `curves` + виньетка; зерно `noise=alls=7:allf=t`
- Звук: синтезированная партитура (ветер, металл, колокол, суб-бас, капли) + озвучка + дакинг
- Контейнер: H.264 High, ~530 кбит/с, AAC 160 кбит/с 48 кГц

## Пересборка

```bash
python src/score.py        # партитура -> build/audio/bed.wav
python src/render.py --scenes all   # шоты -> build/tmp -> out/video_silent.mp4
python src/mix.py          # эмбиент + озвучка -> build/audio/master.wav
python src/subs.py         # .ass субтитры и титры
python src/finalize.py --video out/video_silent.mp4 --crf 28
```

Нужны: `pip install imageio-ffmpeg pillow numpy` (ffmpeg 7 берётся из imageio-ffmpeg).

## Что важно знать о формате

Покадровая анимация (18 720 уникальных рисунков) здесь не создаётся — её нечем рисовать.
Эпизод собран как аниматик: рисованные плейты, снятые виртуальной камерой, с полным
звуковым и монтажным решением. Это стадия, на которой в реальном производстве
утверждают тайминг, свет, звук и драматургию перед запуском полной анимации.

Стилистические ограничения брифа соблюдены: Санни не боец (прячется, травит воду, ждёт),
Горный Король появляется ровно дважды, музыки нет, романтики и юмора нет.
